# 🚀 Personal Fullstack Portfolio

![Portfolio Preview](<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/98bf128f-1bdc-45aa-9339-5b843a7ff2dc" />)

Современное, высокопроизводительное SPA-портфолио, разработанное с нуля. Этот проект демонстрирует мои навыки как Fullstack-разработчика, объединяя надежный бэкенд на **Django** с динамичным, премиальным фронтендом на **Vanilla JS**.

## ✨ Ключевые особенности

*   ⚡ **SPA без фреймворков**: Бесшовная AJAX-навигация между страницами с помощью **Swup.js**. Никаких перезагрузок страницы — мгновенный отклик и плавные переходы.
*   🛡️ **Продвинутая защита контента**: Реализована мощная система защиты авторского права. Полная блокировка DevTools (F12, Ctrl+Shift+I), отключение правой кнопки мыши (ПКМ), запрет на выделение текста, drag-n-drop и скачивание медиа.
*   🎨 **Premium UI/UX & Анимации**: Сложные каскадные анимации при скролле с использованием **GSAP (ScrollTrigger)**, 3D-эффекты для карточек через **Vanilla Tilt** и кастомные интерактивные слайдеры на **Swiper.js**.
*   📊 **Кастомная система аналитики**: Написан собственный Django Middleware для сбора статистики посетителей (отслеживание браузера, ОС, типа устройства, IP) без использования тяжелых сторонних трекеров.
*   ⚙️ **Умная Админ-панель (CMS)**: Полное управление сайтом через панель администратора Django. Удобное добавление проектов, услуг, отзывов и редактирование SEO-метатегов.
*   📱 **100% Адаптивность & SEO**: Mobile-first подход, идеальное отображение на любых устройствах. Оптимизированные Open Graph теги и мета-описания.
*   💬 **Telegram Интеграция**: Мгновенная доставка заявок с формы обратной связи напрямую в Telegram через API.

## 🛠️ Технологический стек

*   **Backend:** Python 3.12, Django 5, SQLite
*   **Frontend:** HTML5, CSS3 (кастомные переменные, Flexbox/Grid), Vanilla JavaScript (ES6+)
*   **Библиотеки:** Swup.js, GSAP, Vanilla Tilt.js, Swiper.js, Lucide Icons
*   **Инструменты:** Git, Pip

## ⚙️ Установка и запуск (Local Environment)

Для запуска проекта на локальной машине выполните следующие шаги:

1. **Клонируйте репозиторий:**
   \\ash
   git clone https://github.com/твое-имя/personal-portfolio.git
   cd personal-portfolio
   \
2. **Создайте и активируйте виртуальное окружение:**
   \\ash
   python -m venv venv
   # Для Windows:
   venv\\Scripts\\activate
   # Для Mac/Linux:
   source venv/bin/activate
   \
3. **Установите зависимости:**
   \\ash
   pip install -r requirements.txt
   \
4. **Примените миграции базы данных:**
   \\ash
   python manage.py migrate
   \
5. **Создайте суперпользователя (для доступа к админке):**
   \\ash
   python manage.py createsuperuser
   \
6. **Запустите сервер разработки:**
   \\ash
   python manage.py runserver
   \
🌐 Проект будет доступен по адресу: \http://127.0.0.1:8000/\  
🔐 Админ-панель: \http://127.0.0.1:8000/admin/
